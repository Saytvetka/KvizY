# Запуск BiletY в Yandex Cloud — по шагам (с iPad)

BiletY живёт рядом с KvizY: тот же каталог, тот же сервисный аккаунт и реестр образов. Отдельные у него только **контейнер `bilety`, база и пароль**. Если KvizY уже запущен по [его инструкции](../../docs/yandex_cloud.md), здесь ~15 минут.

`<FOLDER_ID>` ниже — ID твоего каталога (тот же, что у KvizY). 🟡 — то, что я не мог проверить сам.

---

## Шаг 1. Роль для распознавания фото

YandexGPT картинки не читает, фото и сканы читает **Yandex Vision OCR**.

1. Открой `https://console.yandex.cloud/folders/<FOLDER_ID>/iam/service-accounts` → аккаунт `kvizy`.
2. «Добавить роль» → **`ai.vision.user`**.

Остальные роли (YandexGPT, реестр, контейнеры, YDB) уже есть с KvizY.

## Шаг 2. База для BiletY

1. Открой `https://console.yandex.cloud/folders/<FOLDER_ID>/ydb` → «Создать базу данных», имя `bilety`, тип **Serverless**.
2. На странице базы — «Эндпоинт» вида `grpcs://ydb.serverless.yandexcloud.net:2135/?database=/ru-central1/b1g…/etn…`. Раздели:
   - `BILETY_YDB_ENDPOINT` = `grpcs://ydb.serverless.yandexcloud.net:2135`
   - `BILETY_YDB_DATABASE` = `/ru-central1/b1g…/etn…` (всё после `database=`)

Таблицы приложение создаст само.

## Шаг 3. Пароль — только хэш

Пароль нигде не хранится открытым текстом. Сделай его хэш одним из способов:

- **С iPad, в Safari:** страница-генератор (попроси у Claude ссылку на «Хэш пароля BiletY»). Хэш считается прямо в браузере, пароль никуда не отправляется. Получится строка вида `pbkdf2_sha256$600000$…$…`.
- **На компьютере:** в папке `bilety` запусти `python scripts/hash_password.py`, введи пароль дважды, скопируй строку вида `scrypt$…$…`.

Подходят оба вида хэша.

## Шаг 4. Секреты в GitHub

Открой https://github.com/Saytvetka/KvizY/settings/secrets/actions → «New repository secret». Секреты KvizY (`YC_SA_JSON_CREDENTIALS`, `YC_FOLDER_ID`, `YC_SA_ID`, `YC_REGISTRY_ID`) уже есть и подходят. Добавь:

| Имя | Что вписать |
|---|---|
| `BILETY_PASSWORD_HASH` | хэш пароля из шага 3 |
| `BILETY_SESSION_SECRET` | длинная случайная строка |
| `BILETY_KEY_SECRET` | ещё одна длинная случайная строка. **Не меняй потом** — иначе сохранённые ключи ИИ придётся вводить заново |
| `BILETY_YDB_ENDPOINT` | из шага 2 |
| `BILETY_YDB_DATABASE` | из шага 2 |
| `YANDEX_API_KEY` | *необязательно.* API-ключ YandexGPT. Без него контейнер ходит в YandexGPT и Vision от сервисного аккаунта 🟡 |

`YANDEX_FOLDER_ID` подставляется сам из `YC_FOLDER_ID`. Для секретов-строк: латинские буквы и цифры, **без запятых и пробелов**. Длинную строку удобно сделать в «Пароли» на iPhone → «Новый пароль».

Пока `BILETY_PASSWORD_HASH` не задан, деплой BiletY пропускается (с жёлтым предупреждением), а тесты всё равно идут.

## Шаг 5. Первый запуск

1. Открой https://github.com/Saytvetka/KvizY/actions/workflows/bilety.yml → «Run workflow».
2. Через 3–5 минут в шаге «Новая ревизия контейнера» будет **«Адрес приложения:»** `https://bba….containers.yandexcloud.net/` — это адрес BiletY.
3. Контейнер `bilety` → «Обзор» → включи **«Публичный контейнер»** (один раз, как у KvizY). Без этого — «403 Forbidden».

Дальше каждый пуш в `main` с изменениями в папке `bilety/` обновляет BiletY сам. KvizY при этом не трогается (и наоборот).

## Шаг 6. Проверка

1. `<адрес>/api/health` → `"ok": true`, `"db_kind": "yql"`.
2. `<адрес>` → пароль.
3. Настройки → ИИ → **YandexGPT** → «Проверить связь» → «Работает ✓». Модель: Lite (дёшево) или Pro (умнее).
4. Создать → вставь абзац текста → «Конспект». Потом попробуй фото конспекта — проверишь распознавание.

## Шаг 7. Иконка на экран «Домой»

Safari → адрес → войти → «Поделиться» → «На экран „Домой“» → «Добавить». На iPad «Поделиться» — справа вверху. Пароль вводится один раз в приложении с иконки.

## Сколько стоит (прикидка 🟡)

- **YandexGPT Lite ≈ 0,20 ₽, Pro ≈ 1,20 ₽ за 1000 токенов** 🟡 (https://yandex.cloud/ru/docs/foundation-models/pricing). Лекция на 20 страниц ≈ 12 000 токенов. Билеты или конспект по ней ≈ 16 000 токенов: **≈ 3 ₽ на Lite, ≈ 20 ₽ на Pro.** Ответ на вопрос — меньше. 500 ₽ ≈ 150 результатов на Lite или ~25 на Pro.
- **Распознавание фото** ≈ 0,13 ₽ за страницу 🟡 (цена в `app/config.py → OCR_PRICE_RUB`, поправь по прайсу https://yandex.cloud/ru/docs/vision/pricing).
- Контейнер, база, реестр — в пределах бесплатных квот, как у KvizY.

Точные расходы — внизу Настроек: токены за месяц, сумма из 500 ₽, по видам и моделям. Цены там же можно поправить (Настройки → ИИ → Цена).
